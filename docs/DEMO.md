# The guided tour — see everything in 60 seconds

This is the "wow" walkthrough: a fresh clone, on the **sandbox board**, shows a
full, production-realistic job board with no seeding. The four beats below are
persona-switch → kanban drag → captured email → test-card checkout.

> **Prerequisite:** you're running on the sandbox board (the default in
> `.dev.vars.example`). If the **preview toolbar** isn't visible bottom-left,
> you're not on the sandbox — point `CAVUNO_BOARD` at
> `pk_c2f66367a3abaa6bafd00fd3c2de3297` in `.dev.vars` and restart `pnpm dev`.
> Full reference: [`preview-states.md`](preview-states.md).

> **Recording note:** an animated GIF of this tour is referenced from the
> README (`docs/media/tour.gif`) but must be **recorded separately** — it is

## 1. Switch personas — become a workspace admin

The preview toolbar switches between **8 seeded personas** as real sessions
(it sets a real session cookie, so every page renders as that user).

1. In the bottom-left toolbar, open the persona switcher.
2. Under **Employers**, pick **`employer-admin`**.
3. You are now signed in as an approved workspace admin with a company, jobs,
   and an applicant pipeline — go to `/employers/dashboard`.

> Agents can do this headlessly:
> `switchPersona({ data: { personaId: 'employer-admin' } })` from
> `src/server/preview.ts`. To return to anonymous, **Exit preview** (or
> `exitPreview()`).

## 2. Drag a card across the kanban

The applicant pipeline is a real kanban board — columns are pipeline stages,
cards are applicants, and moves are optimistic (the card jumps immediately and
reverts on error).

1. From the employer dashboard, open one of the company's jobs, then its
   **Applicants** view
   (`/employers/companies/:slug/jobs/:jobId/applicants`).
2. Grab an applicant card by its handle and **drag it to another stage
   column** — or focus a card and move it with the **keyboard** (react-aria's
   drag-and-drop supports both).
3. Watch the card land in the new stage. The same `moveApplicant` server
   function backs both the drag and the detail-sheet stage picker.

## 3. Read a captured email

The sandbox **captures** every outbound email instead of delivering it, so any
flow that "continues in your inbox" is completable on the spot.

1. Toolbar → **Emails** opens a `letter_opener`-style viewer, newest first.
2. Expand a row to render the full captured HTML body.
3. This is how you complete magic-link sign-in, email verification, password
   reset, and job-alert double-opt-in — read the link out of the body and
   follow it.

> To generate a fresh email first (e.g. trigger a password reset or an alert
> confirmation), run the flow, then open **Emails** and hit **Refresh**.
> Headless: `listSandboxEmails({ data: { limit: 50 } })`.

## 4. Check out with a Stripe test card

The sandbox runs Stripe **test mode** — no Stripe account or keys of your own.

1. Reach a checkout: toggle the **Candidate paywall**
   (`jobAccessPaywallEnabled`) in **Board settings** and open a paywall offer,
   **or** run the job-posting funnel at `/post` and pick a paid plan.
2. Pay with a magic test card:

   | Card number | Outcome |
   |---|---|
   | `4242 4242 4242 4242` | Success |
   | `4000 0000 0000 0002` | Decline (generic) |
   | `4000 0000 0000 3155` | 3-D Secure challenge |

   Any future expiry, any CVC, any postal code.
3. On success the grant activates (via webhook for the paywall) and the gated
   surface unlocks.

---

## Reset the sandbox

Personas, board config, and captured emails reset **nightly (23:30 UTC)**. To
reset on demand — e.g. you consumed a one-shot state like an unread-message
badge — use the toolbar's **Reseed** (or `reseedSandbox()`). Reseed restores
the baseline persona roster and board config.
